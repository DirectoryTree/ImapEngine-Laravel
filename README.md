## Installation

Install the package with Composer:

```bash
composer require directorytree/imapengine-laravel
```

## Documentation

See the [installation guide](https://imapengine.com/docs/laravel/installation) to configure your mailboxes, then follow the [Laravel documentation](https://imapengine.com/docs/laravel/introduction) to use them in your application.

For the underlying IMAP API, see [ImapEngine](https://github.com/DirectoryTree/ImapEngine).
